# resources/fonts —— 打包进仓库的开源/免费商用字体

用途：S3 风格层内置视觉稿的 `@font-face` 素材，出片**不依赖观看机器的
系统字体**（尤其楷体/黑体差异大）。渲染器以 `file://` 页面加载这些字体，
配合 Chromium 的 `--allow-file-access-from-files` 即可用。

## 打包规则

- 每款字体放一个子目录，附授权原文（PDF/声明），不要只丢 `.ttf`。
- `render/styles.py::font_face_css()` 启动时自动扫描本目录，凡是
  `ttf / otf / woff2` 都会生成 `@font-face` 注入视觉稿 —— **加字体不用改代码**，
  文件名需能被推断家族名（或在 `styles.py` 的 `_FONT_META` 里登记）。
- 体积意识：单字重中文全量 8MB+ 是常态；优先按需收字重，别整族搬。
- **两层扫描**：本目录随仓库公开（只放允许再分发的字体）；另有本机目录
  `STEPWORK_LOCAL_FONTS`（缺省 `~/.workbuddy/stepwork-fonts`，**不进 git**）
  供「免费商用但禁止公开转发」的字体用 —— 从字由客户端导出的字体请丢那里。
  视觉稿缓存带字体指纹，加/换字体后自动重建。

## 已打包

### alibaba-puhuiti —— 阿里巴巴普惠体 2.0（55 Regular / 65 Medium / 85 Bold）
- 来源：官方下载 `https://done.alibabadesign.com/puhuiti2.0`（OSS 直链解包，取 3 字重 GB18030）
- 许可：免费永久商用（阿里巴巴自有授权，附「使用说明」PDF；注意其条款
  **禁止**未经授权再上传/转发字体文件、禁止修改/反编译 —— 仓库内原样捆绑
  并附授权说明，用于 STEPWORK 自身出片渲染属嵌入式使用）
- 用途：illustration 字幕条 / 通用正文（视觉稿字体栈已首选 `Alibaba PuHuiTi`）

### smiley-sans —— 得意黑（标题/金句爆点字，替代「优设字由棒棒体」气质）
- 来源：GitHub `atelier-anchor/smiley-sans` v2.0.1（OFL-1.1，附授权原文）
- 气质：动感斜切、微笑上扬，综艺/短标题/金句大字 —— 中文网络感标题的上限
- 用途：待出「爆点标题」版式风格时首选字体栈（当前已注入 @font-face 可被引用）

### lxgw-wenkai —— 霞鹜文楷 v1.522 Regular **（A 版纸墨稿的楷体）**
- 来源：GitHub `lxgw/LxgwWenKai` release `v1.522` 直下
  `LXGWWenKai-Regular.ttf`（**25.5 MB**，md5 `b653fcc2aa3130dadead6cd0470e3d76`）
- 许可：**OFL-1.1**（附 `LICENSE-OFL.txt` 原文）。含 Reserved Font Name
  「霞鹜/霞鶩/落霞孤鹜/LXGW」+ 一条附加许可：**重编或子集化**的改版可以沿用保留
  字体名，但**仅限 web font 交付**、且不得作为可安装桌面字体分发。
  ⚠️ 因此本仓库**只捆绑未经修改的原始 TTF**（OFL 明确允许原样再分发）；
  将来若要子集化压体积，先读这条附加许可再决定是否改名。
- 用途：**`ink_text`（A 版纸墨文字稿）字体栈首选**。A 版是 `illustration` 的
  默认降级落点，字形必须跨机器确定 —— 此前栈首选系统楷体（`"Kaiti SC"` /
  `"STKaiti"` / `"KaiTi"`），Windows 落到 `simkai.ttf`，**没装楷体的机器
  （不少 Linux / CI 容器）会一路掉到泛型 `serif` → 宋体**，纸墨气质全无。
  系统楷体栈现已降为兜底（字体目录被清空时才轮到它）。
- 单字重：v1.522 无 Bold，`#txt` 的 `font-weight: 700` 由浏览器**合成粗体** ——
  与现状（系统楷体同样单字重）一致，故不额外进 Medium（再 +24 MB）。
